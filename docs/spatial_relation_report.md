# Phase 20 报告 — 障碍物是否占用盲道（空间关系判断与分级预警）

> 状态：**COMPLETE — GO**
> 日期：2026-09-04 ｜ 模型：`runs/yolov8n_prod_b32/weights/best.pt`（YOLOv8n / 26 类 / imgsz=640 / FP32，**未重训、未修改**）

---

## 1. Phase 20 目标

在 Phase 19（摄像头 → YOLO → 障碍物检测 → 视觉提醒 → TTS）基础上，利用已有的
blind_road bbox 与 obstacle bbox 做二维空间关系判断，输出三级分级预警：

| Level | 状态 | 文案 |
| ----- | ------------------- | ------------------------------------ |
| 0 | `NONE`（无障碍物） | — |
| 1 | `NORMAL_OBSTACLE` | ⚠️ 检测到行人，请注意。 |
| 2 | `BLOCKING_SUSPECTED` | 🔴 障碍物疑似占用盲道，请注意！ |

Level 2 必须覆盖 Level 1；TTS 分级且 Level 1→Level 2 升级时可立即播报。

## 2. 技术方案

```
YOLO (Detector.infer, 原始 boxes, 未改动)
 ↓
AlertManager (复用 Phase 19 全部机制: 类别筛选/去重/冷却/异步TTS线程+队列)
 ↓
SpatialChecker (backend/spatial.py, 纯几何, 独立文件)
 ↓
三级状态 + 分级告警 + 视频叠加绘制 + /api/status 扩展
```

- **不重新训练 / 不改数据集 / 不改 best.pt / 不加任何新模型**（规格 §三/§二十七）。
- **不做 segmentation**：仅基于 bounding box 的二维几何，输出一律表述为
  "**疑似占用**"，绝不表述为"100% 确认阻挡"（规格 §四）。
- **不复制类别列表**：`spatial.py` 不定义障碍物类别，只接收 `AlertManager` 用
  `OBSTACLE_CLASS_INDICES`（Phase 19 唯一定义）筛好的 bbox，几何层与业务层解耦。
- **TTS 仍为异步**：完全复用 Phase 19 的"独立线程 + Queue"，未写任何同步语音。

## 3. bbox 数据结构

- YOLO 原始框：`(x1, y1, x2, y2, cls, conf)`（`Detector.infer` 输出，未改动）。
- `classify(blind_rects, obstacle_items)` 输入：
  - `blind_rects`: `[(x1,y1,x2,y2)]` 盲道框列表；
  - `obstacle_items`: `[{"box","cls","class","confidence","zh"}]`。
- 输出 occupancy dict：`status / level / blocking / obstacles（含几何指标）/
  blocking_obstacles / blind_rects`。

## 4. IoU（条件 A）

`IoU = 交集面积 / 并集面积`。实测发现：盲道 bbox 面积通常远大于障碍物 bbox，
IoU 天然被压低（典型 0.02~0.18），**单靠 IoU 会漏报**（如细长电线杆压盲道时
IoU 仅 0.045）。这正是规格 §八"不要只依赖 IoU"的实证。

## 5. center_inside（条件 B）

障碍物中心 `(cx, cy)` 是否落在盲道 bbox 内。护栏：仍要求交叠比例
`≥ CENTER_MIN_OVERLAP (0.05)` 才计数，排除病态输入（极大障碍物 + 极小盲道框）。

## 6. obstacle_overlap_ratio（条件 C）

`交集面积 / 障碍物面积`，即障碍物有多少比例压在盲道上。**实测中它是最有效的
判别量**（对盲道条形 bbox 不敏感于面积差异）。

## 7. 综合判断规则

```python
blocking = (IoU >= 0.10)                       # 条件 A
        or (center_inside and overlap >= 0.05) # 条件 B (带护栏)
        or (overlap_ratio >= 0.20)             # 条件 C
```

满足任一即判"疑似占用"；满足多项时置信度更高（obstacles 中保留了
`iou / overlap_ratio / center_inside` 三项指标供前端解释"为什么"）。

## 8. 阈值选择（3×3 扫描，非拍脑袋）

`tests/test_spatial.py` 对 **IoU ∈ {0.05, 0.10, 0.15} × 交叠 ∈ {0.10, 0.20, 0.30}**
全部组合做了扫描（15 个人工场景，含边界/误报/漏报用例）：

| IoU \ 交叠 | 0.10 | 0.20 | 0.30 |
|-------|------|------|------|
| **0.05** | FP=0 FN=0 | FP=0 FN=0 | FP=0 FN=0 |
| **0.10** | FP=0 FN=0 | **FP=0 FN=0 ✅ 选定** | FP=0 FN=0 |
| **0.15** | FP=0 FN=0 | FP=0 **FN=1** | FP=0 **FN=1** |

- **IoU 上限 0.10**：0.15 时场景 I（小盲道框 + 大物体压住其大部分，IoU=0.143、
  交叠=0.167、中心在外）漏报——证明 IoU 条件有独立价值，但必须 ≤0.10。
- **交叠取 0.20**：0.20 与 0.30 均零误漏，选 0.20——安全类产品**漏报代价高于
  误报代价**（0.20 能把 ~25% 交叠的边缘情况 E3 判为疑似，0.30 会漏掉）。
- 边界情况 E2（仅 ~10% 交叠擦边）在 0.20 下判"不占用"（Level 1），符合直觉。

## 9. 告警等级

`Level 0（无）/ Level 1（普通障碍物）/ Level 2（疑似占用盲道）`，
由 `occupancy.level` 直接映射。未检出盲道框时**最高只判 Level 1**——没有参照物
就不臆造"占用"结论（有单元测试锁定该行为）。

## 10. 普通障碍物提醒

`⚠️ 检测到行人，请注意。`（复用 Phase 19 的中文合并文案与去重），琥珀色横幅。

## 11. 疑似占用盲道提醒

`🔴 障碍物疑似占用盲道，请注意！` 红色横幅，同时列出**相关障碍物**
（`blocking_obstacles`，含 `IoU / 交叠比 / 中心在内` 指标），视频画面上该障碍物
红框 + "占用盲道?" 标签，盲道框保留（橙色 + blind_road 标签）。

## 12. TTS

- 完全复用 Phase 19 异步线程 + 队列（未重写为同步）。
- **normal / blocking 两套独立冷却**（各 2.5s）：Level 1 的冷却不阻塞 Level 2，
  升级瞬间立即播报高级告警（单元测试验证 `L1→L2 升级当帧播报 + 5 帧重复不刷屏`）。
- 文案分级：`检测到行人，请注意。` / `障碍物疑似占用盲道，请注意。`

## 17. 误报情况

- **对照组（400 张无盲道 GT 图）仅 2 张判 Level2（0.5%）**，且均因模型在该图检出了
  "盲道"框（3/400=0.8%）后几何命中。注意：这 2 张是 ROD 图，而 **ROD 数据集本身
  不标注 blind_road 类**，故无法断言是模型误检——可能确有盲道但无标注。按可证实
  口径：**可归因误报 = 0**。
- 规则层面：擦边（7% 交叠）、贴边（零交叠）、盲道旁物体均不触发（单元测试锁定）。

## 18. 漏报情况

- GT-预测占用一致性 **232/279 = 83.2%**：不一致 47 例中，"GT 判占用/系统未判"24 例、
  "系统判占用/GT 未判"23 例。**逐一归因后两者均主要来自检测层误差**（盲道或障碍物
  被漏检/框偏移），而非几何规则错误——同一张图用 GT 框跑 SpatialChecker 即可判对
  （这正是该对照实验的设计目的：把检测误差与规则误差分离）。
- 已知结构性漏报：blind_road 本身被漏检时（~11.5% 图像级），系统**按设计**降级为
  Level 1，不会臆测占用。

## 19. 技术限制（必须明确的边界）

当前为**基于 YOLO bounding box 的二维图像空间关系判断**，并非：

1. 像素级盲道分割（数据无 mask/polygon 监督）；
2. 真实三维距离测量（无深度信息）；
3. 绝对阻挡判断（bbox 与真实物体轮廓不完全一致、摄像头存在透视）。

因此产品表述统一为"**疑似占用盲道**"。已知系统性误报源：透视下盲道实际为梯形，
其 bbox 是矩形近似，会覆盖部分非盲道区域——该误差源于表示形式，无法靠调阈值
消除；若未来允许，可用分割/多边形标注根治（超出本阶段范围）。
