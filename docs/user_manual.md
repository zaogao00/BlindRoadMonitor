# 用户操作手册 — 智能盲道障碍物监测与预警系统

> 本文面向**不需要懂 Python** 的使用者。照着做即可。

---

## 一、你需要准备什么

- 一台装了 **Windows 11** 的电脑，带 **NVIDIA 显卡**（本项目在 RTX 5070 Laptop 上验证）
- 一个**摄像头**（笔记本自带摄像头或 USB 摄像头都可以）
- **音箱或耳机**（用于听到语音提醒）；没有声音设备也能用，画面和文字提醒照常工作

---

## 二、五步开始使用

### 第一步：双击启动

打开文件夹：

```text
D:\BlindRoadMonitor\scripts\
```

双击 **`start_web.bat`**。

会弹出一个黑色命令行窗口，显示启动进度。

### 第二步：等待服务启动

首次启动需要加载模型，**大约等待 3~30 秒**。

当窗口里出现类似下面的内容，说明已经就绪：

```text
[web][worker] 模型加载成功: ... (类数=26)
[web][worker] 源已打开: kind=camera resolution=640x480
```

> 如果窗口里出现红色错误并停在"请按任意键继续"，请看本文**第四节：出问题怎么办**。

**注意：这个黑色窗口要一直开着，不要关掉。关掉就等于停止服务。**

### 第三步：打开浏览器

打开 Edge 或 Chrome，在地址栏输入：

```text
http://127.0.0.1:8000
```

回车后即可看到系统页面。

### 第四步：把摄像头对准道路

将摄像头对准**有人行盲道的路面**。页面左侧是实时画面，右侧是状态面板。

画面里会有彩色框：

| 框的颜色 | 含义 |
| -------- | ---- |
| 橙色 | 盲道（blind_road） |
| 绿色 | 普通障碍物（不影响盲道） |
| **红色 + "占用盲道?"** | **疑似占用盲道的障碍物** |

### 第五步：观察提醒

系统会用**两种**方式提醒你：

**1）画面下方的横幅**

| 横幅 | 含义 |
| ---- | ---- |
| ⚠️ 琥珀色：`检测到行人，请注意。` | Level 1：发现障碍物，但没有证据表明它占用盲道 |
| 🔴 红色：`障碍物疑似占用盲道，请注意！` | Level 2：障碍物疑似压在盲道上，**请特别注意** |

**2）语音播报**

- Level 1：`检测到行人，请注意。`
- Level 2：`障碍物疑似占用盲道，请注意。`

语音**每 2.5 秒最多播报一次**，不会一句话反复念。
如果情况从 Level 1 升级到 Level 2，会**立刻**播报一次高级提醒。

## 三、页面上的状态怎么看

| 显示项 | 说明 |
| ------ | ---- |
| Camera | `Connected` 摄像头正常；`Error` 未打开（鼠标悬停可看原因） |
| Model | `Loaded` 模型已加载 |
| Stream FPS | 实际画面帧率（端到端） |
| Model FPS | YOLO 推理本身的速度 |
| 分辨率 | 摄像头实际协商出的分辨率，如 `640x480` |
| Blind Road | `Detected` 画面中找到盲道；`Not Detected` 没找到 |
| Obstacles | 当前检测到的障碍物数量 |
| **盲道占用** | `未发现` / **`疑似`**（红字） |
| **告警等级** | `0 · 无` / `1 · 普通障碍物` / `2 · 疑似占用盲道` |
| TTS 语音 | `可用` 或 `不可用`（不可用时仍保留画面与文字提醒） |

## 四、出问题怎么办

### 1. 双击 bat 后窗口一闪就没了 / 提示找不到虚拟环境

说明 `D:\BlindRoadMonitor.venv` 不存在或被移动过。
请联系维护者按 `docs/deployment_guide.md` 的"安装"章节重建环境。

### 2. 提示端口被占用

换一个端口启动：

```bat
cd /d D:\BlindRoadMonitor
D:\BlindRoadMonitor.venv\Scripts\python.exe scripts\run_web.py --port 8010
```

然后浏览器访问 `http://127.0.0.1:8010`。

### 3. Camera 显示 Error（摄像头打不开）

常见原因：

- **摄像头被其他程序占用**（系统"相机"应用、腾讯会议、钉钉、Zoom 等）→ 关掉它们再启动
- 摄像头索引不对 → 换一个索引试试：

```bat
D:\BlindRoadMonitor.venv\Scripts\python.exe scripts\run_web.py --source 1
```

（`--source 0` 是第一个摄像头，`1` 是第二个，以此类推）

### 4. 画面很卡 / FPS 很低

- 关掉其他占用显卡的程序
- 降低摄像头分辨率：

```bat
D:\BlindRoadMonitor.venv\Scripts\python.exe scripts\run_web.py --width 320 --height 240
```

- 30 FPS 以上属于正常达标，不必追求 60 FPS

### 5. 一直检测不到盲道（Blind Road = Not Detected）

- 把摄像头**对准并靠近**盲道，让它占据画面中部较大区域
- 光线太暗、盲道严重磨损、距离过远都会导致漏检
- 可以适当降低置信度阈值（更多检测，但也可能更多误报）：

```bat
D:\BlindRoadMonitor.venv\Scripts\python.exe scripts\run_web.py --conf 0.15
```

### 6. 没有声音

- 检查系统音量、默认输出设备
- 页面右侧 `TTS 语音` 显示 `不可用` 时，说明本机语音引擎初始化失败 —— **画面和文字提醒仍然正常工作**
- 鼠标悬停在"不可用"上可看到具体错误

---

## 五、如何退出

1. 在黑色命令行窗口按 **`Ctrl + C`**，等待出现"服务已正常停止"
2. 或直接**关闭黑色窗口**
3. 关闭浏览器标签页

---

## 六、使用前请务必知道的局限

- 系统输出的是"**疑似占用盲道**"，**不是**"确认阻挡"。
- 它基于二维图像中的矩形框判断，**没有深度信息**，也不做像素级分割。
- **画面里没找到盲道时，系统不会判断"占用"**，只会提示有障碍物。
- 本系统是**辅助提示工具，不能替代盲杖、导盲犬或他人协助**，请勿作为唯一的安全依据。
